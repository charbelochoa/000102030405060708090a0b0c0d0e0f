# Referencias locales

Este directorio reúne las inspiraciones y recursos originales proporcionados para el proyecto.

```text
design/linear/       Captura de interfaz, CSS y 977 módulos JavaScript
design/apple-music/ Captura y recursos de Apple Music
cli/claude-code/    Referencia de CLI
assets/css/         CSS de referencia
assets/typography/  Tipografía local
```

El código activo está en `src`, `server`, `shared`, `cli` y `desktop`. El mapeo de adaptación se documenta en `docs/REFERENCIAS.md`. Este archivo se versiona; los paquetes originales se conservan localmente para no mezclar capturas y recursos con los artefactos de AERIS.
